# ContractAI Review — User Guide by Topic

This user guide is structured by topic so an LLM or help system can quickly find and retrieve relevant sections to answer user questions like "How do I…?" or "What is…?". Each topic is a separate file with clear, step-by-step instructions.

## Purpose

- **For end users**: Step-by-step help for using ContractAI Review
- **For LLMs/help systems**: Topic-based content for RAG or context loading when answering support questions

## Format

Each topic file is self-contained with:

1. **Title and summary** — What the feature is and when to use it
2. **Prerequisites** — What the user must have done first
3. **Steps** — Numbered, concrete actions
4. **Options / variations** — Alternative flows where applicable
5. **Related topics** — Links to other user-guide files
